The loop, in six pieces

Everything below is running on the page you're reading.

🖍️

Rectangle feedback

Hold Alt/Option and drag a box over anything on the live page. Ordinary clicks still use the site. Each point carries exact element context, so your agent knows precisely what "this" means.

🎙️

Say it, don't type it

Live speech-to-text in the note editor. Describe the change the way you'd tell a designer standing next to you.

⏪

Before / after from git

The review bar swaps the current feedback target against the pre-round commit, with a one-click whole-site view when you need it. No screenshots, no squinting.

⚖️

Verdict every point

Accept, delete, or redo - per point, in the browser. Deletes revert the exact commit; redos come back in the next round.

🔤

A/B/C variants

Any point can ask for lettered takes - described by you or invented by the model - switchable live before you commit to one. (Try the button in the footer.)

🖐️

Five agents, five colors

Atomic color locks and emoji-stamped tabs keep parallel agents from ever colliding - you always know which tab belongs to whom.
